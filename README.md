# acute_traits
Data and code associated with "Rapid heat stress assays predict survivors of coral bleaching"

https://assets-eu.researchsquare.com/files/rs-7863661/v1/f31deca5-63cc-466e-9b57-4859eab4079f.pdf 

Scripts include:

1.) Metrics_v_bleaching_mortality.Rmd: for comparisons of acute metrics to in-situ bleaching and mortality

2.) Traits_over_time.Rmd: for comparisons of acute traits over time
